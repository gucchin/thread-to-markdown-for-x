**A・B の原因と修正**

- 原因：X は、スレッドの続きの長文ポストを「さらに表示」で省略して描画する。この「さらに表示」は、別ページへのリンクではなく、**その場で全文を展開する `<button>`** だった（`tests/fixtures/raw/thread-ng.html` で確認）。抽出は省略されたままの本文をコピーし、警告を付けるだけだった
- 修正：`src/content/expandTruncated.ts` を追加。抽出後、省略されたスレッドのポストがあれば、その「さらに表示」ボタンを押し、展開されるのを MutationObserver で待って（上限 3 秒）抽出し直す
  - 押すのはスレッドのポストのボタンだけ（他者のリプライのものは押さない）
  - `<a>` の「さらに表示」と、引用カード内のものは押さない（ページを離れてしまうため）
  - 3 秒で展開されなければ、これまでどおり警告を付けてコピーする
  - 全文の取得は X 自身の処理が行う。拡張機能自体は通信しない
- 確認
  - NG のページを匿名化して `tests/fixtures/show_more.html` にし、問題を再現するテスト（警告 2 件）と、展開後に全文が入り警告が消えるテストを追加した（`tests/expandTruncated.test.ts`、10 件）
  - 組み上がった `dist/content.js` を、X の展開を模したページで動かし、展開された全文がコピーされ、警告が出ないことを確認した
  - ボタンを押さない、リンクも押す、抽出し直さない、の 3 通りに一時的に壊すと、テストが失敗することを確認した
- 再確認で見てほしいこと（A・B）
  - 長文を含むスレッドで、コピー後に X の画面でも省略されていた本文が展開されていること（ボタンを押した結果）
  - 貼り付けた Markdown に警告が無く、本文が最後まで入っていること
  - ボタンを押してからトーストが出るまでが極端に遅くないこと（展開待ちで最大 3 秒）
  - **気になる点**：展開を待つ間に、ブラウザがクリップボードへの書き込みを拒否する可能性がある（ボタン操作からの経過時間の制限）。その場合でもページ側の 2 段目のコピーかポップアップの再試行でコピーできるはずだが、失敗のトーストが出たら教えてほしい

## 実機テストの手順（ユーザー作業）

### 準備

1. `chrome://extensions` を開き、「X Thread to Markdown」の更新ボタン（↻）を押す（`dist/` は最新の内容でビルド済み）
2. 開いている x.com のタブをすべて再読み込みする（拡張を更新する前に開いたタブには新しいコンテンツスクリプトが入っていないため）

### A. ページ内ボタン

1. 同じ人が複数件続けて投稿しているスレッドの 1 件目を開く（`thread.html` を取ったポストで良い）
2. メインポストのアクションバー（返信・リポスト・いいねのアイコン列）の下に「Copy as Markdown」ボタンが出ることを確かめる
3. ボタンを押す → 右下にトースト「✅ N posts copied as Markdown」が出て、3 秒で消えることを確かめる
4. メモ帳などに貼り付け、次を確かめる
   - 先頭が `# X Thread by @...` で、`- Posts:` の件数が画面のスレッドの件数と合っている
   - 本文・画像の URL・引用が入っている
   - 本文中のリンクが `…` で終わらず、完全な URL になっている
5. ボタンを押したときに、ポストの詳細ページに移動してしまわないこと

### B. ポップアップ

1. A と同じページで、ツールバーの拡張アイコンを押してポップアップを開く
2. 「Copy thread as Markdown」を押す → ポップアップに「✅ N posts copied as Markdown」か「✅ Copied as Markdown」が出ることを確かめる（どちらでも良い。後者はポップアップ側で再試行してコピーしたことを表す）
3. 貼り付けて、A と同じ内容になっていることを確かめる

### C. ページ遷移（SPA）

1. A のページから、別のポストをクリックして開く → ボタンがそのポストの下に 1 つだけ出る
2. 左のメニューから「ホーム」へ移動 → ボタンがどこにも残っていない
3. ブラウザの「戻る」でポストに戻る → ボタンが 1 つだけ出る

### D. 使えないページ

1. 新しいタブ（`chrome://newtab`）でポップアップを開く → ボタンが無効で「Open a post on x.com to copy its thread.」
2. x.com のホームでポップアップを開く → ボタンが無効で「Open a single post (x.com/<user>/status/<id>) to copy its thread.」

### E. 再読み込みの案内

1. `chrome://extensions` で拡張の更新ボタン（↻）を押す
2. x.com のポストのタブを**再読み込みせずに**、ポップアップのボタンを押す → 「Reload the page and try again …」と出る

### F. 見た目

- トーストとボタンが X の表示を崩していないか（ライト／ダークのどちらかで良い。両方見られればなお良い）
- トーストに枠や色が付いているか（スタイル無しの素の文字になっていたら、X の CSP でスタイルが効いていない）

### G. エラーの有無

- DevTools（F12）のコンソールに、この拡張由来の赤いエラーが出ていないか（`content.js` の名前が付いたもの）

### 結果の伝え方

各項目について「OK」か、うまくいかなかった点（表示されたメッセージ・スクリーンショット・コンソールのエラー文）を教えてください。うまくいかない場合でも、その時点の `main` の HTML をフィクスチャと同じ方法で `tests/fixtures/raw/` に保存してもらえると、原因を調べられます。

### 追加のフィクスチャ（余裕があれば）

取り方はこれまでと同じです（`tests/fixtures/raw/<名前>.html` に保存）。次のコマンドを使うと URL も一緒に記録できます。

```js
copy('<!-- url: ' + location.href + ' -->\n' + document.querySelector('main').outerHTML)
```
