# ストア掲載文（日本語）

Chrome Web Store Developer Dashboard の「ストアの掲載情報」タブで、言語に日本語を追加して貼り付ける文章。
README.ja.md と実装に合わせ、実装にない機能は書かない（PLAN.md §16.3）。

- カテゴリ：仕事効率化（Productivity）
- 言語：日本語（英語版は `listing.en.md`）

## 概要（短い説明）

概要は `manifest.json` の `description` から取られ、ダッシュボードでは編集できない。拡張機能は多言語化（`_locales`）
していないので、日本語の掲載ページでも概要は英語のまま表示される（`listing.en.md` と同じ文）。日本語の概要を出すには
`_locales` が必要で、これはスコープ外（PLAN.md §16.1）。

## 詳しい説明

```text
X（旧 Twitter）のスレッドを、ChatGPT・Claude などの LLM に貼り付けたり、Notion・Obsidian に保存したりしやすい Markdown にして、クリップボードへコピーします。

使い方
ポストのページ（x.com/<ユーザー>/status/<ID>）を開いて、次のどれかを使います。
・メインポストの下に出る「Copy as Markdown」ボタン
・ツールバーの拡張機能アイコン →「Copy thread as Markdown」
・ショートカット Alt+Shift+M（chrome://extensions/shortcuts で変更できます）

コピーされる内容
・スレッドの著者のポストを順番どおりに（開いたポストより上の分も含みます）
・本文（改行・絵文字・リンク・ハッシュタグ。リンクは X が表示している場合は完全な URL）
・画像の URL（大きいサイズまたは元のサイズ）、動画・GIF のサムネイル画像
・引用ポスト（Markdown の引用として）
・各ポストの日時と URL
・「さらに表示」で省略された長文は、展開してからコピーします

設定
・コピーするポスト：著者のスレッドのみ／メインポスト以降のすべて（他の人の返信を含む）
・自動スクロール：画面外のポストを集めるため自動で下にスクロールします（最大 100 件・30 秒。途中で止めることもできます）
・画像サイズ：Large／Original
・各ポストの日時と URL：HTML コメント（Obsidian・Notion のプレビューでは非表示）／通常の行
・Obsidian：YAML frontmatter（title・author・source・date・posts・tags）を付ける

プライバシー
・外部への通信は一切しません。表示した内容やコピーした内容を収集・保存・送信することはありません
・読み取るのは、あなたのブラウザで表示中の x.com / twitter.com のページだけです。X の API は使いません
・保存するのは設定だけです（Chrome の同期がオンなら同期されます）

既知の制約
・コピーできるのは、ページに読み込まれているポストだけです。X は画面外のポストを消すため、長いスレッドでは自動スクロールをオンにしてください
・「もっと見つける」（おすすめ）より下のポストは含めません
・動画・GIF はサムネイル画像の URL だけで、動画そのものは含みません
・画像の代替テキスト（ALT）は含みません
・拡張機能のインストール・更新より前に開いていた x.com のタブは、再読み込みしてください
・X の画面構造が変わると動かなくなることがあります。その場合は更新で対応します

無料・オープンソース（MIT ライセンス）：
https://github.com/gucchin/thread-to-markdown-for-x

この拡張機能は X Corp. とは関係がなく、承認を受けたものでもありません。
```
