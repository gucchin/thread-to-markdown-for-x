## 使い方

```sh
# 生の HTML は tests/fixtures/raw/ に置く（.gitignore 済み）
node scripts/anonymize.mjs tests/fixtures/raw/<case>.html tests/fixtures/<case>.html --url https://x.com/<handle>/status/<id>
```

- ページ URL は、生 HTML の 1 行目の `<!-- url: ... -->` か `--url` で渡す。出力の 1 行目に匿名化後の URL が入り、テストはそこからメインの ID を読む
- 取得時は次のコマンドを使うと URL も一緒にコピーできる
  `copy('<!-- url: ' + location.href + ' -->\n' + document.querySelector('main').outerHTML)`
- URL を記録し忘れた場合は、メインポスト（自分の `time` が `User-Name` の外にある `article`）の `time` を囲むリンクから求められる。今回の 5 ファイルはこの方法で求めた
- テストからは `import html from './fixtures/<case>.html?raw'` と `loadFixture(html)`（`tests/helpers/dom.ts`）で読む

## 作業メモ

- 置き換えるもの
  - ハンドル（`userN`）と表示名（`User N`）
  - ステータス ID、数値ユーザー ID（`<id>-follow`）
  - 画像 ID、動画サムネイルの ID とハッシュ（`amplify_video_thumb` などのディレクトリ名は、GIF 判定に使える可能性があるので残す）
  - アバター URL
  - t.co リンク（広告の `twclid` も消える）とハッシュタグ
  - 本文：同じ長さのダミー語にする。改行と行頭の `#`・`>`・`-`・`*`・`` ` `` は残す
  - 本文中の URL：`https://example.com/linkN/partM…` の分割構造を残す
- 残すもの：構造、`data-testid`・`role`、日時、絵文字、表示数・いいね数などの数値、UI の文言
- 難読化クラス（`class` 属性）はすべて削除する。テストが誤って依存しないようにするためで、サイズも半分になる
- ログイン中のユーザー自身の情報（返信欄のアバター）も匿名化の対象にしている
- 最後に、元の値が残っていないか、ハンドルの入る位置がすべて `userN` 形式かを検査し、問題があれば失敗する
- 全 5 ファイルで確認したこと：2 回目の実行で出力が完全に一致すること（冪等性）。漏れについては、スクリプトとは独立した検査で、元のハンドルの 5 文字の部分文字列・本文の単語・8 桁以上の数値・画像 ID・t.co を検索した。見つかったのは表示数（数値）と、X がセッションごとに振るランダムな ID（`typeaheadFocus-0.xxx`）だけで、どちらも個人を特定しないので残している
- 開発中に見つけて直した不具合
  - 表示名がハンドルの部分文字列だと（例：表示名 "Abc" とハンドル "xyzAbc"）ハンドルの一部が残っていた。ハンドルを先に置き換え、表示名は本文と `aria-label`・`alt`・`title` だけで置き換えるようにした
  - ダミー本文が空白で終わると、再実行時に長さが変わって冪等にならなかった
