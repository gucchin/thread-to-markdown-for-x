# 026 ストアへの提出・審査対応・公開後の更新手順

- Day：4
- 依存：023, 024, 025
- 参照：PLAN.md §16.8, §16.9

## 目的

Chrome ウェブストアに提出して公開し、以後の更新の手順を整える（Day 4 の完了条件）。

## Todo

- [ ] 提出（ユーザー作業）
  - [ ] Chrome Web Store Developer Dashboard でデベロッパー登録（初回のみ登録料。2 段階認証が必要）
  - [ ] 新しいアイテムとして zip（025）をアップロード
  - [ ] 掲載情報・画像・プライバシーへの取り組み・ポリシー URL を入力（023・024）
  - [ ] 公開範囲（021）を選んで審査に提出
- [ ] 審査対応：不承認の場合は理由を共有してもらい、修正して再提出する（理由と対応を作業メモに記録）
- [ ] 公開後の確認（ユーザー作業）：ストアからインストールした版で 3 経路のコピー・設定・自動スクロールが動く
- [ ] `CHANGELOG.md` を作り、1.0.0 の内容を書く
- [ ] README・CLAUDE.md に更新の手順を書く（修正 → テスト → `version` を上げる → `npm run package` → アップロードして提出）

## 完了条件（Day 4 の完了条件を兼ねる）

- [ ] 審査を通過してストアで公開されている
- [ ] ストアからインストールした版で、3 経路のコピーが動く
- [ ] README（GitHub）にストアへのリンクがある
