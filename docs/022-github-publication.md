  - docs/003 と `scripts/anonymize.mjs` のコメントに、匿名化の失敗例として実在のハンドル名が書いてあった → 架空の例に置き換えた
  - 2 回目の確認（2026-10-16）：フィクスチャに残る文字列とリンク先をすべて書き出して目で確認したところ、ログイン中のアカウントの表示名（返信欄のアバター）・別の形で描画されたいいね数・リンクカードと X の記事の文章・広告のリンクの追跡パラメータ（`twclid`）が残っていた。名前や ID だけを探す漏れチェックでは見つからなかった。匿名化スクリプトを直して全 11 件を作り直し、ガードテストを追加した（詳細は docs/003）
- 投稿日時は元のまま（反応数を消せば、日時だけで元のポストを探すのは現実的でないと判断。ずらすと匿名化の冪等性と両立しにくい）
- フィクスチャの HTML の骨組みは X のページのもの（文章・名前・画像・リンクは置き換え済み、クラス名は削除済み）。テスト用として置くのは一般的と判断
- 最終確認（2026-10-16、最初のコミットに対して）
  - コミットされた 124 ファイルに、匿名化前のデータ・zip・`dist/`・`node_modules/`・個人用ファイルが無い
