## 作業メモ

- 設定は `chrome.storage.sync` の 1 つのキー `settings` にまとめて保存する。読み込み時に `normalizeSettings` で項目ごとに検証し、不正な値・欠けた値は既定値で補う（古い版や将来の版の値で壊れないように）。読み込みに失敗した場合も既定値で動く（例外を出さない）
- `ImageResolution` の型は `shared/settings.ts` に移した（`parseMedia` は再エクスポート）
- オプションページは保存ボタンなしで、変更のたびに保存して「Saved.」を表示する。保存は読み込み→マージ→書き込みなので、連続した変更で片方が消えないよう直列化している（テストあり。直列化を外すミューテーションで落ちることを確認）
- コンテンツスクリプトは実行のたびに設定を読む。オプションページやポップアップで変えた設定が、ページを再読み込みせずに反映される
- manifest：`"options_ui": { "page": "options.html", "open_in_tab": false }`（`chrome://extensions` の「拡張機能のオプション」のダイアログ内に表示）。権限の追加はなし（`storage` は既存）
- 016 の時点で実際に効くのは画像解像度だけ。モード・frontmatter・メタ情報の形式は 017 で出力に反映する

### 実機確認（ユーザー作業）

1. `npm run build` → `chrome://extensions` で拡張を再読み込み
2. 拡張の「詳細」→「拡張機能のオプション」を開く。5 項目が既定値（Thread by the author only / Auto-scroll オフ / Large / HTML comment / frontmatter オフ）で表示される
3. 項目を変えると「Saved.」が出る。オプションを閉じて開き直しても変えた値のまま
4. 画像解像度を Original にしてから画像付きポストでコピーすると、画像 URL が `name=orig` になる
