## 作業メモ

- 表示文言は `src/shared/labels.ts` の `describeResponse(response)` にまとめた（ポップアップと共用）。1 件のときは「1 post」と単数形にする
- エラーの文言はコードごとに決めた固定文。内部の詳細（`message`）は `UNKNOWN` のときだけ添える
- 決めたこと
  - 成功・警告は 3 秒で消える。手動コピー欄の無いエラーは、読む時間が要るので 6 秒にした
  - 手動コピー欄があるトーストは、閉じるボタン（×）を押すまで残る。テキストエリアにフォーカスすると全文を選択する
  - **ポップアップから実行してコピーに失敗した場合は、ページにトーストを出さない**。ポップアップ側でコピーを再試行し、手動コピーも出すため（014）。ページの「コピー失敗」とポップアップの「コピー成功」が食い違うのを防ぐ。そのために要求に `source`（`button`・`popup`・`shortcut`）を加えた。`source` の無い要求は `popup` 扱い
- スタイルは Shadow DOM の中に置く。構築可能なスタイルシート（`adoptedStyleSheets`）を優先し、使えない環境（jsdom）では `<style>` 要素にする（`src/content/ui/styles.ts`）。`:host { all: initial }` で X の CSS の継承も断つ
- テスト：`tests/toast.test.ts`（20 件）。表示・属性、HTML として解釈しないこと、置き換え、3 秒・6 秒での消去、手動コピー欄と閉じるボタン、古いタイマーが新しいトーストを消さないこと、文言、ポップアップ由来のコピー失敗を出さないこと
- **実機で確認すること（015）**
  - X の CSP の下で、構築可能なスタイルシートが効くか（効かないとトーストがスタイル無しで表示される）
  - X の画面の上に重なって、右下に表示されるか
