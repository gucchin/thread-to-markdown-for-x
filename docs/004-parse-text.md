## 作業メモ

- **実 DOM で分かったこと**：X は URL を「非表示の `https://`」＋「表示部分」＋「非表示の残り」＋「`…`」の span に分けて描画する。`textContent` は完全な URL の末尾に `…` が付いた形になるので、末尾の `…` を除いてから URL 形式か判定する（PLAN.md §7.3 の規則だけだと `…` 付きの URL が出力される）
- 引用カードの中では URL がリンクではなく、同じ構造の `<span>` で表示される。これも同じ規則で復元する
- 各行の末尾の空白も削除している
